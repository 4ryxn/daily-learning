# Installing Anaconda

## What is Anaconda Distribution?

**Anaconda Distribution** is a Python distribution designed mainly for:

* Data Science
* Machine Learning
* Data Analysis
* Scientific Computing

It provides many commonly used tools together, including:

* Python
* Conda
* Jupyter Notebook
* JupyterLab
* Anaconda Navigator
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

Instead of installing Python and Data Science libraries individually, Anaconda provides a convenient ready-to-use environment.

---

## Installing Anaconda on Windows

### Step 1: Download Anaconda

Download **Anaconda Distribution** from the official Anaconda website.

Choose the correct installer for your operating system.

### Step 2: Run the Installer

Open the downloaded `.exe` file and follow these steps:

1. Click **Next**.
2. Accept the license agreement.
3. Select **Just Me** for a personal installation.
4. Choose the installation directory.
5. Continue with the installation.

### Should Anaconda Be Added to PATH?

During installation, Windows may show an option like:

```text
Add Anaconda3 to my PATH environment variable
```

It is generally better **not to manually add the complete Anaconda installation to PATH**, because it may interfere with other Python installations.

Instead, beginners can use:

* **Anaconda Prompt**
* **Anaconda Navigator**

Conda can also be initialized for a terminal using:

```bash
conda init
```

---

## Installing Anaconda on macOS

General steps:

1. Download the correct Anaconda installer.
2. Open the `.pkg` installer.
3. Follow the installation instructions.
4. Open **Terminal** after installation.
5. Verify that Conda is working.

---

## Installing Anaconda on Linux

Download the installer and run it from the terminal:

```bash
bash Anaconda3-<version>-Linux-x86_64.sh
```

Then:

1. Accept the license terms.
2. Select the installation directory.
3. Allow Anaconda to initialize Conda.
4. Restart the terminal.

---

## Verify the Installation

Run:

```bash
conda --version
```

You can also use:

```bash
conda info
```

or:

```bash
conda list
```

If these commands work correctly, Anaconda and Conda have been installed successfully.
