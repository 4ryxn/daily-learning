# Adding Conda to Environment Variables

## What is an Environment Variable?

An **environment variable** stores information that the operating system and applications can use.

One important environment variable is:

```text
PATH
```

---

## What is PATH?

The **PATH environment variable** contains a list of directories where the operating system searches for executable programs.

For example, when we type:

```bash
python
```

or:

```bash
conda
```

the operating system needs to know where these programs are located.

---

## Common Conda Error

Sometimes the terminal may show:

```text
conda: command not found
```

or on Windows:

```text
'conda' is not recognized as an internal or external command
```

Possible reasons include:

* Conda is not installed correctly.
* The terminal was not restarted after installation.
* Conda has not been initialized.
* The shell cannot locate Conda.

---

## Recommended Method: `conda init`

Instead of manually adding every Anaconda directory to PATH, Conda can initialize itself for your shell.

Run:

```bash
conda init
```

Then close and reopen the terminal.

---

## Initialize Conda for a Specific Shell

### Bash

```bash
conda init bash
```

### Zsh

```bash
conda init zsh
```

### PowerShell

```powershell
conda init powershell
```

After running the command, restart the terminal.

---

## Windows Users

### Option 1: Use Anaconda Prompt

Search for:

```text
Anaconda Prompt
```

Conda is normally already configured inside Anaconda Prompt.

### Option 2: Initialize PowerShell

Run:

```powershell
conda init powershell
```

Then restart PowerShell.

---

## Why Not Add Everything to PATH Manually?

Permanently adding the complete Anaconda installation to PATH may create conflicts with:

* Other Python installations
* Development tools
* Applications using their own Python versions

Conda environments are designed to modify the required paths when an environment is activated.

Example:

```bash
conda activate data_science
```

---

## Verify Conda

Run:

```bash
conda --version
```

or:

```bash
conda info
```

If Conda responds correctly, the shell configuration is working.

---
