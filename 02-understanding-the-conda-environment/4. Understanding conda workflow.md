# Understanding Conda Workflow

## What is Conda?

**Conda** is used for:

1. **Package Management**
2. **Environment Management**

It is especially useful in Data Science because different projects may require different versions of Python and libraries.

---

## Why Do We Need Conda Environments?

Suppose two projects require different versions of the same library:

```text
Project A → Package Version 1
Project B → Package Version 2
```

Installing everything globally may create conflicts.

Conda solves this problem by creating **isolated environments**.

---

## What is a Conda Environment?

A **Conda environment** is an isolated workspace containing its own:

* Python version
* Packages
* Dependencies

For example:

```text
base
│
├── data_science
├── machine_learning
└── project_1
```

Each environment can have different packages and versions.

---

# Basic Conda Workflow

```text
Create Environment
       ↓
Activate Environment
       ↓
Install Packages
       ↓
Work on Project
       ↓
Deactivate Environment
```

---

## 1. Check Conda

```bash
conda --version
```

or:

```bash
conda info
```

---

## 2. Create an Environment

Syntax:

```bash
conda create --name <environment_name>
```

Example:

```bash
conda create --name data_science
```

---

## Create an Environment with Python

```bash
conda create --name data_science python
```

A specific Python version can also be used:

```bash
conda create --name data_science python=3.12
```

---

## 3. Activate the Environment

```bash
conda activate data_science
```

After activation, the terminal may show:

```text
(data_science)
```

This indicates that the environment is active.

---

## 4. Install Packages

Syntax:

```bash
conda install <package_name>
```

Example:

```bash
conda install pandas
```

Install multiple packages:

```bash
conda install numpy pandas matplotlib
```

---

## 5. View Installed Packages

```bash
conda list
```

---

## 6. View All Environments

```bash
conda env list
```

or:

```bash
conda info --envs
```

Example:

```text
base
data_science *
machine_learning
```

The `*` indicates the currently active environment.

---

## 7. Deactivate the Environment

```bash
conda deactivate
```

---

## 8. Remove an Environment

```bash
conda env remove --name data_science
```

---

# The `base` Environment

Conda creates a default environment called:

```text
base
```

The `base` environment contains Conda itself and some basic packages.

For projects, it is usually better to create separate environments instead of installing everything into `base`.

Example:

```text
base
│
├── ds_learning
├── ml_project
└── analysis_project
```

---

# Packages and Dependencies

## Package

A **package** is software that can be installed into an environment.

Examples:

* NumPy
* Pandas
* Matplotlib
* Scikit-learn

Example:

```bash
conda install pandas
```

---

## Dependency

A **dependency** is another package required by a package to work.

Example:

```text
Package A
   ↓
requires
   ↓
Package B
```

Conda automatically tries to install compatible dependencies.

---

# Conda Channels

A **channel** is a source from which Conda downloads packages.

One popular community-maintained channel is:

```text
conda-forge
```

Example:

```bash
conda install -c conda-forge package_name
```

Here:

```text
-c
```

specifies the channel.

---

## Essential Conda Commands

| Task               | Command                                 |
| ------------------ | --------------------------------------- |
| Check Conda        | `conda info`                            |
| Create environment | `conda create --name myenv`             |
| Create with Python | `conda create --name myenv python=3.12` |
| Activate           | `conda activate myenv`                  |
| Install package    | `conda install pandas`                  |
| List packages      | `conda list`                            |
| List environments  | `conda env list`                        |
| Deactivate         | `conda deactivate`                      |
| Remove environment | `conda env remove --name myenv`         |

---

## Quick Revision

```text
Create → Activate → Install → Work → Deactivate
```

Example:

```bash
conda create --name ds_learning python=3.12
conda activate ds_learning
conda install numpy pandas matplotlib
conda list
conda deactivate
```
