# Anaconda Navigator: Quick Tour

## What is Anaconda Navigator?

**Anaconda Navigator** is a graphical user interface provided with Anaconda Distribution.

It allows users to manage Data Science tools without typing every Conda command manually.

Navigator can be used to:

* Launch applications
* Create environments
* Install packages
* Update packages
* Remove packages
* Manage Conda environments

---

# Main Sections of Anaconda Navigator

## 1. Home

The **Home** section displays applications available through Anaconda.

Common applications may include:

* JupyterLab
* Jupyter Notebook
* Spyder
* Other installed tools

Applications can be opened directly using the **Launch** button.

---

## 2. Environments

The **Environments** section is used to manage Conda environments.

You can:

* Create environments
* Delete environments
* Select environments
* Install packages
* Remove packages
* Update packages
* Search for packages

---

# Creating an Environment Using Navigator

General workflow:

```text
Open Navigator
      ↓
Environments
      ↓
Create
      ↓
Enter Environment Name
      ↓
Select Python Version
      ↓
Create
```

The graphical process performs a similar task to:

```bash
conda create --name myenv python
```

---

# Installing Packages Using Navigator

To install a package:

1. Open **Environments**.
2. Select the required environment.
3. Search for the package.
4. Select the package.
5. Click **Apply**.

Examples of packages:

```text
numpy
pandas
matplotlib
scikit-learn
```

This provides a graphical alternative to:

```bash
conda install pandas
```

---

# Launching Jupyter from Navigator

From the **Home** section:

```text
JupyterLab → Launch
```

or:

```text
Jupyter Notebook → Launch
```

The application will normally open inside your web browser.

---

# Navigator vs Conda Command Line

| Anaconda Navigator            | Conda CLI                     |
| ----------------------------- | ----------------------------- |
| Graphical interface           | Command-line interface        |
| Easier for beginners          | Faster for experienced users  |
| Uses buttons and menus        | Uses commands                 |
| Visual environment management | Terminal-based management     |
| Visual package management     | Scriptable package management |

Both work with the same underlying **Conda environments and packages**.

---

## When is Navigator Useful?

Navigator is useful when:

* You are new to Conda.
* You prefer graphical interfaces.
* You want to quickly launch Jupyter.
* You want to visually manage packages.
* You want to create environments without remembering commands.
