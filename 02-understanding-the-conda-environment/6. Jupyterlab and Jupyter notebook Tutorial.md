# JupyterLab and Jupyter Notebook Tutorial

## What is Jupyter?

**Jupyter** provides an interactive environment where code, explanations, outputs, and visualizations can exist together.

Jupyter notebooks commonly use the file extension:

```text
.ipynb
```

A notebook may contain:

* Python code
* Text
* Mathematical equations
* Tables
* Images
* Graphs
* Data visualizations
* Program output

This makes notebooks especially useful for Data Science.

---

# Jupyter Notebook

**Jupyter Notebook** provides an interface mainly focused on creating and running notebook files.

It is commonly used for:

* Learning Python
* Data analysis
* Data visualization
* Machine Learning experiments
* Research
* Documentation

---

# JupyterLab

**JupyterLab** is a more complete interactive Data Science workspace.

It can work with:

* Jupyter notebooks
* Text files
* Markdown files
* CSV files
* Terminals
* Code consoles
* Images

It also allows multiple files to be opened using tabs and panels.

---

# Jupyter Notebook vs JupyterLab

| Feature          | Jupyter Notebook          | JupyterLab                     |
| ---------------- | ------------------------- | ------------------------------ |
| Main Purpose     | Notebook-focused work     | Complete interactive workspace |
| `.ipynb` Support | Yes                       | Yes                            |
| Multiple Tabs    | Limited compared with Lab | Yes                            |
| File Browser     | Basic                     | More advanced                  |
| Terminal         | Limited workflow          | Integrated                     |
| Text Editor      | Basic                     | Integrated                     |
| Best For         | Simple notebook work      | Larger Data Science workflows  |

Both use the same `.ipynb` notebook format.

2. Select a Python notebook/kernel.


# Notebook Cells

A Jupyter Notebook is divided into **cells**.

The two most important cell types are:

1. Code Cells
2. Markdown Cells

---

## Code Cell

A **Code Cell** contains executable code.

Example:

```python
x = 10
y = 20

x + y
```

Output:

```text
30
```

---

## Markdown Cell

A **Markdown Cell** contains formatted text.

Example:

```markdown
# Data Analysis

## Pandas

Pandas is used for **data manipulation and analysis**.
```

Markdown cells are useful for:

* Headings
* Notes
* Explanations
* Documentation
* Lists

---

# Running a Cell

A commonly used shortcut is:

```text
Shift + Enter
```

It:

1. Runs the current cell.
2. Moves to the next cell.

---

# Edit Mode and Command Mode

Jupyter notebooks mainly have two interaction modes.

## Edit Mode

Used when typing inside a cell.

Shortcut:

```text
Enter
```

---

## Command Mode

Used when performing actions on entire cells.

Shortcut:

```text
Esc
```

---

# Important Keyboard Shortcuts

| Shortcut               | Action                   |
| ---------------------- | ------------------------ |
| `Shift + Enter`        | Run current cell         |
| `Enter`                | Enter Edit Mode          |
| `Esc`                  | Enter Command Mode       |
| `A`                    | Add cell above           |
| `B`                    | Add cell below           |
| `M`                    | Convert cell to Markdown |
| `Y`                    | Convert cell to Code     |
| `D`, `D`               | Delete selected cell     |
| `Ctrl + S` / `Cmd + S` | Save notebook            |

# What is a Kernel?

A **kernel** is the process that executes the code inside a notebook.

For a Python notebook:

```text
Code Cell
    ↓
Python Kernel
    ↓
Execute Code
    ↓
Return Output
```

---

## Kernel Memory

Variables created in one executed cell remain available while the kernel is running.

### Cell 1

```python
name = "Aryan"
```

### Cell 2

```python
print(name)
```

Output:

```text
Aryan
```

The second cell works because the kernel remembers the `name` variable.

---

# Restarting the Kernel

Sometimes the notebook's current state becomes confusing.

You can restart the kernel using:

```text
Kernel → Restart Kernel
```

Restarting clears variables and objects stored in memory.

---

# Why Execution Order Matters

Notebook cells can be executed in any order.

Example:

### Cell 1

```python
x = 10
```

### Cell 2

```python
print(x)
```

Cell 2 works only if Cell 1 has already been executed.

Running cells randomly can create confusing results because old values may remain in memory.

A good practice before finalizing a notebook is:

```text
Restart Kernel
      ↓
Run All Cells
      ↓
Check Results
```

# Common Beginner Mistakes

## 1. Running Cells in Random Order

This may create hidden state and confusing outputs.

Use:

```text
Restart Kernel → Run All
```

before finalizing important notebooks.

---

## 2. Forgetting to Save

Save regularly using:

```text
Ctrl + S
```

or on macOS:

```text
Cmd + S
```

---

## 3. Using the Wrong Environment

When multiple Conda environments exist, make sure Jupyter is using the correct Python kernel.

---

## 4. Forgetting to Activate the Environment

Before launching Jupyter from a project environment:

```bash
conda activate ds_learning
```

Then:

```bash
jupyter lab
```
