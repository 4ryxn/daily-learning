# List Comprehensions

**List comprehension** is a concise and efficient way to create lists in Python.

It allows a list to be generated in a single line of code, making simple list-building logic more readable and Pythonic.

---

# Basic Syntax

```python
[expression for item in iterable]
```

Where:

- `expression` → operation performed on each item
- `item` → variable representing each element
- `iterable` → data being iterated over, such as a list or `range()`

---

# 1. Basic List Comprehension

### Example: Creating Squares

```python
squares = [x**2 for x in range(5)]

print(squares)
```

Output:

```text
[0, 1, 4, 9, 16]
```

Equivalent idea using a regular loop:

```python
squares = []

for x in range(5):
    squares.append(x**2)
```

List comprehension provides a shorter form when the logic is simple.

---

# 2. List Comprehension with `if`

Conditions can be used to filter elements.

### Example: Filtering Even Numbers

```python
evens = [x for x in range(10) if x % 2 == 0]

print(evens)
```

Output:

```text
[0, 2, 4, 6, 8]
```

Only values satisfying:

```python
x % 2 == 0
```

are included.

---

# 3. List Comprehension with `if-else`

An `if-else` expression can transform values based on a condition.

```python
numbers = [
    "Even" if x % 2 == 0 else "Odd"
    for x in range(5)
]

print(numbers)
```

Output:

```text
['Even', 'Odd', 'Even', 'Odd', 'Even']
```

---

# 4. Nested Loops in List Comprehension

Multiple loops can appear inside one comprehension.

```python
pairs = [
    (x, y)
    for x in range(2)
    for y in range(3)
]

print(pairs)
```

Output:

```text
[(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2)]
```

---

# 5. List Comprehension with Functions

Methods or functions can be applied to every element.

### Example: Converting Strings to Uppercase

```python
words = ["hello", "world", "python"]

upper_words = [word.upper() for word in words]

print(upper_words)
```

Output:

```text
['HELLO', 'WORLD', 'PYTHON']
```

---

# 6. Flattening a Nested List

List comprehension can flatten a two-dimensional list.

```python
matrix = [
    [1, 2],
    [3, 4],
    [5, 6]
]

flattened = [
    num
    for row in matrix
    for num in row
]

print(flattened)
```

Output:

```text
[1, 2, 3, 4, 5, 6]
```

---

# 7. Set and Dictionary Comprehensions

The same idea can also be used with sets and dictionaries.

## Set Comprehension

```python
unique_numbers = {x for x in [1, 2, 2, 3, 4, 4]}

print(unique_numbers)
```

Output:

```text
{1, 2, 3, 4}
```

## Dictionary Comprehension

```python
squared_dict = {x: x**2 for x in range(5)}

print(squared_dict)
```

Output:

```text
{0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

---

# When to Use List Comprehensions

Use list comprehensions when:

- You need to create a list in a single line.
- The logic is simple and readable.
- You want a concise way to generate or filter values.

Avoid them when the logic becomes too complex.

In that case, use a regular loop for better clarity.

---

# Performance

The refresher notes that list comprehensions are generally faster than equivalent loops because they are optimized internally by Python.

### Regular Loop

```python
squares_loop = []

for x in range(10**6):
    squares_loop.append(x**2)
```

### List Comprehension

```python
squares_comp = [x**2 for x in range(10**6)]
```

For simple list creation, the comprehension is usually more concise.

|---|---|
| Basic | `[x**2 for x in range(5)]` |

Prefer a normal loop when a comprehension becomes difficult to understand.
