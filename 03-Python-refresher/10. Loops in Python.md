# Loops in Python

Loops are used to **repeat a block of code multiple times**.

Python mainly provides two types of loops:

1. `for` loop
2. `while` loop

---

# 1. For Loop

A `for` loop is used to iterate over sequences such as:

- Lists
- Tuples
- Strings

## Basic Syntax

```python
for item in sequence:
    # code to execute
```

### Example

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Output:

```text
apple
banana
cherry
```

### How It Works

On each iteration, one element from the sequence is stored in the loop variable.

Here:

```python
for fruit in fruits:
```

`fruit` takes the values:

```text
apple
banana
cherry
```

one by one.

---

# Using `range()`

`range()` is commonly used when we want to repeat something a specific number of times.

### Example

```python
for i in range(3):
    print(i)
```

Output:

```text
0
1
2
```

`range(3)` generates values starting from `0` and stopping before `3`.

---

# 2. While Loop

A `while` loop runs **as long as its condition remains `True`**.

## Basic Syntax

```python
while condition:
    # code to execute
```

### Example

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

Output:

```text
0
1
2
```

### How It Works

Initially:

```python
count = 0
```

The condition:

```python
count < 3
```

is checked before every iteration.

After printing the value, `count` is increased by `1`.

The loop stops when the condition becomes `False`.

---

# Loop Control Statements

Python provides loop control statements to change the normal execution of a loop.

| Statement | Purpose |
|---|---|
| `break` | Exits the loop immediately |
| `continue` | Skips the current iteration and moves to the next one |
| `pass` | Does nothing and is used as a placeholder |

---

## `break`

`break` immediately terminates the loop.

### Example

```python
for i in range(5):
    if i == 3:
        break

    print(i)
```

Output:

```text
0
1
2
```

When `i` becomes `3`, the `break` statement stops the loop.

---

## `continue`

`continue` skips the current iteration and moves to the next iteration of the loop.

---

## `pass`

`pass` performs no operation.

It is useful as a placeholder when Python expects a statement but no action needs to be performed yet.

---

# `for` vs `while`

| `for` Loop | `while` Loop |
|---|---|
| Used to iterate over a sequence | Runs while a condition is `True` |
| Common with lists, tuples, and strings | Common when repetition depends on a condition |
| Can be used with `range()` | Requires the condition to eventually become `False` |

---

# Quick Revision

- Python has two main loops: `for` and `while`.
- `for` is used to iterate over sequences.
- `range()` can generate values for a `for` loop.
- `while` runs while its condition remains `True`.
- `break` exits a loop.
- `continue` skips the current iteration.
- `pass` does nothing and acts as a placeholder.
