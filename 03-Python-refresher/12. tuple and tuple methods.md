# Tuples and Tuple Methods

A **tuple** in Python is an **ordered and immutable collection of elements**.

A tuple is similar to a list, but its elements **cannot be modified after the tuple is created**.

---

# Creating a Tuple

## Empty Tuple

```python
empty_tuple = ()
```

## Tuple with Elements

```python
numbers = (1, 2, 3, 4, 5)
```

## Tuple with Mixed Data Types

```python
mixed_tuple = (1, "Hello", 3.14, True)
```

---

# Single-Element Tuple

A comma is required when creating a tuple containing only one element.

```python
single_element = (42,)
```

The comma is important.

---

# Common Tuple Methods

Tuples provide fewer methods than lists because tuples are immutable.

| Method | Description |
|---|---|
| `count(x)` | Returns how many times `x` appears |
| `index(x)` | Returns the index of the first occurrence of `x` |

---

# `count()`

Counts how many times a value appears in the tuple.

```python
my_tuple.count(2)
```

---

# `index()`

Returns the index of the first occurrence of a value.

```python
my_tuple.index(3)
```

---

# Accessing Tuple Elements

Tuple elements can be accessed using indexing.

```python
my_tuple = (10, 20, 30, 40)

print(my_tuple[1])
```

Output:

```text
20
```

---

# Tuple Slicing

Tuples can also be sliced.

```python
my_tuple = (10, 20, 30, 40)

print(my_tuple[1:3])
```

Output:

```text
(20, 30)
```

---

# Tuple Packing

Storing multiple values inside a tuple is called **tuple packing**.

```python
person = ("Alice", 25, "Engineer")
```

Here, three values are packed into one tuple.

---

# Tuple Unpacking

Tuple unpacking means assigning tuple elements to separate variables.

```python
person = ("Alice", 25, "Engineer")

name, age, profession = person

print(name)
print(age)
```

Output:

```text
Alice
25
```

Here:

```python
name
```

gets `"Alice"`,

```python
age
```

gets `25`, and

```python
profession
```

gets `"Engineer"`.

---

# Tuple Characteristics

## 1. Immutable

Once a tuple is created, its elements cannot be changed.

## 2. Faster than Lists

The refresher notes that accessing tuple elements is faster than accessing list elements.

## 3. Can Be Used as Dictionary Keys

Since tuples are immutable, they can be used as dictionary keys.

---

# When to Use Tuples

Tuples are useful:

- When you want an unchangeable collection of elements.
- When you need a faster alternative to lists.
- When storing heterogeneous data such as:
  - Database records
  - Coordinates

---

# List vs Tuple

| List | Tuple |
|---|---|
| Ordered | Ordered |
| Mutable | Immutable |
| Uses `[]` | Uses `()` |
| Can be modified | Cannot be modified after creation |
| Has many modification methods | Mainly provides `count()` and `index()` |

---

# Quick Revision

```python
numbers = (1, 2, 3)

numbers.count(2)
numbers.index(3)
```

### Important Points

- Tuples are ordered.
- Tuples are immutable.
- A single-element tuple requires a comma: `(42,)`.
- Tuple elements support indexing and slicing.
- Tuple packing stores multiple values together.
- Tuple unpacking assigns those values to separate variables.
