# Variables, Data Types and Typecasting

## Variables

A **variable** is a container used to store a data value.

In Python, we do not need to explicitly declare the data type of a variable. Python automatically determines the type based on the value assigned to it.

### Example

```python
name = "Alice"
age = 25
is_student = True
```

Here:

- `name` stores a string.
- `age` stores an integer.
- `is_student` stores a Boolean value.

---

## Common Data Types

Python provides different data types for storing different kinds of values.

| Data Type | Example | Description |
|---|---|---|
| `int` | `10`, `-5` | Integer numbers |
| `float` | `3.14`, `-0.5` | Decimal numbers |
| `str` | `"hello"` | Text or string |
| `bool` | `True`, `False` | Boolean values |
| `list` | `[1, 2, 3]` | Ordered, mutable collection |
| `tuple` | `(1, 2, 3)` | Ordered, immutable collection |
| `dict` | `{"a": 1}` | Collection of key-value pairs |

---

## Checking the Data Type

The built-in `type()` function is used to check the data type of a variable.

### Example

```python
age = 25

print(type(age))
```

Output:

```text
<class 'int'>
```

---

# Typecasting

**Typecasting**, also called **type conversion**, means converting a value from one data type to another.

Python provides built-in functions such as:

- `int()`
- `float()`
- `str()`
- `list()`

---

## String to Integer

```python
x = int("10")

print(x)
```

Output:

```text
10
```

The string `"10"` is converted into the integer `10`.

---

## Integer to String

```python
y = str(25)

print(y)
```

The integer `25` is converted into the string `"25"`.

---

## Float to Integer

```python
z = int(3.9)

print(z)
```

Output:

```text
3
```

`int()` removes the decimal portion of the float.

It **truncates the value instead of rounding it**.

```python
int(3.9)   # 3
```

---

## String to List

```python
lst = list("abc")

print(lst)
```

Output:

```text
['a', 'b', 'c']
```

Each character of the string becomes a separate element in the list.

---

## Typecasting Errors

A value must be compatible with the target data type.

For example:

```python
int("hello")
```

This produces:

```text
ValueError
```

because `"hello"` cannot be converted into an integer.

---

## Quick Revision

- Variables are containers used to store values.
- Python does not require explicit data type declaration.
- Use `type()` to check the type of a variable.
- `int` stores integers.
- `float` stores decimal numbers.
- `str` stores text.
- `bool` stores `True` or `False`.
- `list` is ordered and mutable.
- `tuple` is ordered and immutable.
- `dict` stores key-value pairs.
- Typecasting converts one data type into another.
- `int(3.9)` gives `3`, not `4`.
- Invalid type conversions can raise a `ValueError`.
