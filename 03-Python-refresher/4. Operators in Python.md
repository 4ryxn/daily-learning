# Operators in Python

Operators are symbols or keywords used to perform operations on values and variables.

The main types of operators are:

1. Arithmetic Operators
2. Comparison Operators
3. Logical Operators
4. Bitwise Operators
5. Assignment Operators
6. Membership Operators
7. Identity Operators

---

# 1. Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Assume:

```python
a = 10
b = 5
```

| Operator | Description | Example | Result |
|---|---|---|---|
| `+` | Addition | `a + b` | `15` |
| `-` | Subtraction | `a - b` | `5` |
| `*` | Multiplication | `a * b` | `50` |
| `/` | Division | `a / b` | `2.0` |
| `//` | Floor Division | `a // b` | `2` |
| `%` | Modulus | `a % b` | `0` |
| `**` | Exponentiation | `a ** b` | `100000` |

---

## Division `/`

Normal division returns a floating-point result.

```python
10 / 5
```

Output:

```text
2.0
```

---

## Floor Division `//`

Floor division returns the floored result of division.

```python
10 // 5
```

Output:

```text
2
```

---

## Modulus `%`

The modulus operator returns the remainder after division.

```python
10 % 5
```

Output:

```text
0
```

Another example:

```python
10 % 3
```

Output:

```text
1
```

---

## Exponentiation `**`

Exponentiation raises a number to a power.

```python
10 ** 5
```

Output:

```text
100000
```

---

# 2. Comparison Operators

Comparison operators compare values and return either `True` or `False`.

Assume:

```python
a = 10
b = 5
```

| Operator | Description | Example | Result |
|---|---|---|---|
| `==` | Equal to | `a == b` | `False` |
| `!=` | Not equal to | `a != b` | `True` |
| `>` | Greater than | `a > b` | `True` |
| `<` | Less than | `a < b` | `False` |
| `>=` | Greater than or equal to | `a >= b` | `True` |
| `<=` | Less than or equal to | `a <= b` | `False` |

---

## `=` vs `==`

A common beginner mistake is confusing assignment with comparison.

```python
a = 10
```

`=` assigns the value `10` to `a`.

```python
a == 10
```

`==` checks whether `a` is equal to `10`.

---

# 3. Logical Operators

Logical operators are used to combine conditional expressions.

Assume:

```python
x = True
y = False
```

| Operator | Description | Example | Result |
|---|---|---|---|
| `and` | True when both conditions are True | `x and y` | `False` |
| `or` | True when at least one condition is True | `x or y` | `True` |
| `not` | Reverses the Boolean value | `not x` | `False` |

---

## `and`

Both conditions must be `True`.

```python
True and True
```

Output:

```text
True
```

```python
True and False
```

Output:

```text
False
```

---

## `or`

At least one condition must be `True`.

```python
True or False
```

Output:

```text
True
```

---

## `not`

Reverses a Boolean value.

```python
not True
```

Output:

```text
False
```

---

# 4. Bitwise Operators

Bitwise operators perform operations at the **bit level**.

Assume:

```python
a = 5
b = 3
```

| Operator | Description | Example | Result |
|---|---|---|---|
| `&` | Bitwise AND | `a & b` | `1` |
| `\|` | Bitwise OR | `a \| b` | `7` |

### Example

```python
5 & 3
```

Output:

```text
1
```

```python
5 | 3
```

Output:

```text
7
```

---

# 5. Assignment Operators

Assignment operators are used to assign or update values stored in variables.

| Operator | Example | Equivalent To |
|---|---|---|
| `=` | `a = 5` | `a = 5` |
| `+=` | `a += 5` | `a = a + 5` |
| `-=` | `a -= 5` | `a = a - 5` |
| `*=` | `a *= 5` | `a = a * 5` |
| `/=` | `a /= 5` | `a = a / 5` |
| `//=` | `a //= 5` | `a = a // 5` |
| `%=` | `a %= 5` | `a = a % 5` |
| `**=` | `a **= 5` | `a = a ** 5` |

### Example

```python
a = 10

a += 5

print(a)
```

Output:

```text
15
```

This is equivalent to:

```python
a = a + 5
```

---

# 6. Membership Operators

Membership operators check whether a value exists inside a sequence or collection.

Assume:

```python
lst = [1, 2, 3]
x = 2
```

| Operator | Description | Example | Result |
|---|---|---|---|
| `in` | Checks whether a value is present | `x in lst` | `True` |
| `not in` | Checks whether a value is absent | `x not in lst` | `False` |

### Example

```python
2 in [1, 2, 3]
```

Output:

```text
True
```

```python
5 not in [1, 2, 3]
```

Output:

```text
True
```

---

# 7. Identity Operators

Identity operators check whether two references point to the same object.

| Operator | Description |
|---|---|
| `is` | Checks whether both references point to the same object |
| `is not` | Checks whether they point to different objects |

### Example

```python
a = [1, 2]
b = [1, 2]

print(a is b)
```

Output:

```text
False
```

Although the values inside both lists are equal, `a` and `b` are two separate objects.

---

## `==` vs `is`

| Operator | Checks |
|---|---|
| `==` | Whether values are equal |
| `is` | Whether references point to the same object |

# Operator Precedence

When multiple operators appear in the same expression, Python evaluates them according to **operator precedence**.

For arithmetic operations, Python follows the PEMDAS-style order:

1. Parentheses `()`
2. Exponentiation `**`
3. Multiplication `*`, Division `/`, Floor Division `//`, Modulus `%`
4. Addition `+`, Subtraction `-`

---

## Example 1

```python
result = 10 + 2 * 3

print(result)
```

Output:

```text
16
```

Multiplication happens first:

```text
10 + (2 * 3)
10 + 6
16
```

---

## Example 2

```python
result = (10 + 2) * 3

print(result)
```

Output:

```text
36
```

Parentheses are evaluated first:

```text
(10 + 2) * 3
12 * 3
36
```

---

## Exponentiation Order

Exponentiation is evaluated from **right to left**.

```python
result = 2 ** 3 ** 2
```

Python evaluates it as:

```python
2 ** (3 ** 2)
```

Therefore:

```text
3 ** 2 = 9

2 ** 9 = 512
```

Output:

```text
512
```

# Quick Revision

| Operator Category | Operators |
|---|---|
| Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` |
| Comparison | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| Logical | `and`, `or`, `not` |
| Bitwise | `&`, `\|` |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` |
| Membership | `in`, `not in` |
| Identity | `is`, `is not` |

## Important Points

- `/` performs normal division.
- `//` performs floor division.
- `%` returns the remainder.
- `**` performs exponentiation.
- Comparison operators return `True` or `False`.
- `=` is assignment, while `==` is comparison.
- `and`, `or`, and `not` are logical operators.
- `in` and `not in` check membership.
- `is` and `is not` check object identity.
- Parentheses can be used to control the order of evaluation.
