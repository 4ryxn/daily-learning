# String Formatting and f-Strings

String formatting allows us to insert values, variables, and expressions inside strings.

Python provides multiple ways to format strings, including:

1. `format()`
2. f-strings

**f-strings are the recommended and more readable approach in modern Python.**

---

# 1. Using `format()`

The `format()` method inserts values into `{}` placeholders inside a string.

## Basic Example

```python
name = "Alice"
age = 25

print("My name is {} and I am {} years old.".format(name, age))
```

Output:

```text
My name is Alice and I am 25 years old.
```

The values passed to `format()` are inserted into the `{}` placeholders.

---

# Positional Arguments with `format()`

Positions can be specified inside the placeholders.

```python
print("{0} is learning {1}".format("Alice", "Python"))
```

Output:

```text
Alice is learning Python
```

Here:

- `{0}` refers to `"Alice"`
- `{1}` refers to `"Python"`

---

# Keyword Arguments with `format()`

Names can also be used inside placeholders.

```python
print(
    "{name} is learning {language}".format(
        name="Alice",
        language="Python"
    )
)
```

Output:

```text
Alice is learning Python
```

---

# 2. f-Strings

f-strings provide a cleaner and more readable way to format strings.

They were introduced in **Python 3.6**.

## Syntax

Place `f` before the string:

```python
f"Text {variable}"
```

---

## Example

```python
name = "Alice"
age = 25

print(f"My name is {name} and I am {age} years old.")
```

Output:

```text
My name is Alice and I am 25 years old.
```

Variables are placed directly inside `{}`.

---

# Expressions Inside f-Strings

Python expressions can also be evaluated directly inside `{}`.

```python
a = 5
b = 10

print(f"Sum of {a} and {b} is {a + b}")
```

Output:

```text
Sum of 5 and 10 is 15
```

The expression:

```python
a + b
```

is evaluated before being inserted into the string.

---

# Formatting Numbers

f-strings can control how numeric values are displayed.

### Example: Two Decimal Places

```python
pi = 3.14159

print(f"Pi rounded to 2 decimal places: {pi:.2f}")
```

Output:

```text
Pi rounded to 2 decimal places: 3.14
```

The format:

```python
:.2f
```

means display the floating-point number using **2 decimal places**.

---

# Padding and Alignment

f-strings can also align text within a specified width.

Consider:

```python
print(f"{'Python':<10}")
print(f"{'Python':>10}")
print(f"{'Python':^10}")
```

## Left Alignment

```python
f"{'Python':<10}"
```

`<` means left-align the text inside a width of `10` characters.

---

## Right Alignment

```python
f"{'Python':>10}"
```

`>` means right-align the text.

---

## Center Alignment

```python
f"{'Python':^10}"
```

`^` means center-align the text.

---

# `format()` vs f-Strings

| Feature | `format()` | f-Strings |
|---|---|---|
| Basic placeholders | `{}` | `{variable}` |
| Variables written directly | No | Yes |
| Expressions inside string | Less direct | Yes |
| Readability | Good | Cleaner |
| Recommended in modern Python | Less preferred | Yes |

---

### Important Points

- `format()` inserts values into placeholders.
- Positional and keyword arguments can be used with `format()`.
- f-strings were introduced in Python 3.6.
- f-strings are cleaner and more readable.
- Variables and expressions can be placed directly inside `{}`.
- `:.2f` formats a number to two decimal places.
- `<`, `>`, and `^` are used for left, right, and center alignment.
- f-strings are the recommended string-formatting approach in modern Python.
