# Sets and Set Methods

A **set** in Python is an **unordered, mutable collection of unique elements**.

Important properties:

- Sets do not allow duplicate values.
- Sets are unordered.
- Sets do not support indexing or slicing.
- Elements can be added or removed.

---

# Creating a Set

## Empty Set

An empty set must be created using `set()`.

```python
empty_set = set()
```

Do not use:

```python
{}
```

for an empty set because `{}` represents an empty dictionary.

---

## Set with Elements

```python
numbers = {1, 2, 3, 4, 5}
```

---

## Set with Mixed Data Types

```python
mixed_set = {1, "Hello", 3.14, True}
```

---

# Removing Duplicate Values

Sets automatically remove duplicate elements.

```python
unique_numbers = set([1, 2, 2, 3, 4, 4, 5])

print(unique_numbers)
```

Output:

```text
{1, 2, 3, 4, 5}
```

---

# Common Set Methods

| Method | Description |
|---|---|
| `add(x)` | Adds one element |
| `update(iterable)` | Adds multiple elements |
| `remove(x)` | Removes an element and raises an error if it is not found |
| `discard(x)` | Removes an element without raising an error if it is missing |
| `pop()` | Removes and returns an element |
| `clear()` | Removes all elements |
| `copy()` | Returns a shallow copy |

---

# `add()`

Adds one element to the set.

```python
my_set.add(10)
```

---

# `update()`

Adds multiple elements from an iterable.

```python
my_set.update([6, 7, 8])
```

---

# `remove()`

Removes a specified element.

```python
my_set.remove(3)
```

If the element is not present, `remove()` raises an error.

---

# `discard()`

Also removes a specified element.

```python
my_set.discard(3)
```

Unlike `remove()`, `discard()` does **not raise an error** when the value is not found.

---

# `pop()`

Removes and returns an element from the set.

```python
my_set.pop()
```

---

# `clear()`

Removes all elements from the set.

```python
my_set.clear()
```

---

# `copy()`

Creates a shallow copy of the set.

```python
new_set = my_set.copy()
```

---

# Set Operations

Suppose:

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}
```

Python provides several important set operations.

---

# Union

The **union** combines all unique elements from both sets.

Using the method:

```python
set1.union(set2)
```

Using the operator:

```python
set1 | set2
```

Example:

```python
print(set1 | set2)
```

Output:

```text
{1, 2, 3, 4, 5, 6}
```

---

# Intersection

The **intersection** returns elements that exist in both sets.

Using the method:

```python
set1.intersection(set2)
```

Using the operator:

```python
set1 & set2
```

Example:

```python
print(set1 & set2)
```

Output:

```text
{3, 4}
```

---

# Difference

The **difference** returns elements that are present in `set1` but not in `set2`.

Using the method:

```python
set1.difference(set2)
```

Using the operator:

```python
set1 - set2
```

Example:

```python
print(set1 - set2)
```

Output:

```text
{1, 2}
```

---

# Symmetric Difference

The **symmetric difference** returns elements that exist in either set, but not in both.

Using the method:

```python
set1.symmetric_difference(set2)
```

Using the operator:

```python
set1 ^ set2
```

Example:

```python
print(set1 ^ set2)
```

Output:

```text
{1, 2, 5, 6}
```

---

# `issubset()`

Checks whether all elements of one set are contained inside another set.

```python
set1.issubset(set2)
```

It returns either:

```text
True
```

or:

```text
False
```

---

# `issuperset()`

Checks whether one set contains all elements of another set.

```python
set1.issuperset(set2)
```

It returns either:

```text
True
```

or:

```text
False
```

---

# Set Operation Summary

| Operation | Method | Operator |
|---|---|---|
| Union | `union()` | `\|` |
| Intersection | `intersection()` | `&` |
| Difference | `difference()` | `-` |
| Symmetric Difference | `symmetric_difference()` | `^` |

---

# Key Properties of Sets

## Unordered

Sets do not maintain elements by index.

Therefore, sets do not support:

- Indexing
- Slicing

## Unique Elements

Duplicate values are automatically removed.

## Mutable

Elements can be added or removed after the set is created.

### Important Points

- Sets are unordered.
- Sets contain unique elements.
- Sets are mutable.
- Sets do not support indexing or slicing.
- Use `set()` to create an empty set.
- `remove()` raises an error when an element is missing.
- `discard()` does not raise an error when an element is missing.
- Union combines unique elements.
- Intersection finds common elements.
- Difference finds elements present in one set but not the other.
- Symmetric difference finds elements present in either set, but not both.
