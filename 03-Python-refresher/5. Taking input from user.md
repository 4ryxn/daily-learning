# Taking Input from the User

Python uses the built-in `input()` function to take input from the user.

## Basic Syntax

```python
variable = input("Message to display: ")
```

### Example

```python
name = input("Enter your name: ")

print("Hello", name)
```

The message inside `input()` is displayed to the user, and the entered value is stored in the variable.

---

## Important Point: `input()` Always Returns a String

The `input()` function always returns the entered value as a **string**, even if the user enters a number.

```python
age = input("Enter your age: ")

print(type(age))
```

If the user enters:

```text
25
```

the value is still stored as:

```python
"25"
```

which is a string.

---

# Type Conversion with `input()`

When numeric input is required, convert the string returned by `input()` into the required data type.

## Integer Input

```python
age = int(input("Enter your age: "))
```

Here:

1. `input()` receives the value as a string.
2. `int()` converts it into an integer.

---

## Float Input

```python
price = float(input("Enter the price: "))
```

Here, the entered value is converted into a floating-point number.

---

## Example

```python
age = int(input("Enter your age: "))
price = float(input("Enter the price: "))

print(age)
print(price)
```

---

# Quick Revision

- `input()` is used to take input from the user.
- `input()` always returns a string.
- Use `int()` when integer input is required.
- Use `float()` when decimal input is required.

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))
price = float(input("Enter the price: "))
```
