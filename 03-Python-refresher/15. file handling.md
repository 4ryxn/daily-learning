# File Handling in Python

**File handling** allows Python programs to read, write, and manipulate files stored on disk.

Python provides the built-in `open()` function for working with files.

---

# Opening a File

## Syntax

```python
file = open("filename", mode)
```

Where:

- `filename` → name or path of the file
- `mode` → specifies how the file should be opened

---

# File Modes

| Mode | Description |
|---|---|
| `'r'` | Read mode; raises an error if the file does not exist |
| `'w'` | Write mode; creates a file or overwrites existing content |
| `'a'` | Append mode; adds content without removing existing content |
| `'x'` | Creates a new file; fails if the file already exists |
| `'b'` | Binary mode for files such as images and PDFs |
| `'t'` | Text mode; default mode for text files |

Binary and text modes can be combined with other modes.

Examples:

```python
"rb"
"wb"
"ab"
"rt"
"wt"
```

---

# Reading Files

## `read()`

`read()` reads the entire contents of a file.

```python
file = open("example.txt", "r")

content = file.read()

print(content)

file.close()
```

Always close the file after working with it when using `open()` directly.

---

# `readline()`

`readline()` reads one line from the file.

```python
file = open("example.txt", "r")

line1 = file.readline()

print(line1)

file.close()
```

---

# `readlines()`

`readlines()` reads all lines and returns them as a list.

```python
file = open("example.txt", "r")

lines = file.readlines()

print(lines)

file.close()
```

---

# Writing to Files

## `write()`

The `'w'` mode is used to write content.

```python
file = open("example.txt", "w")

file.write("Hello, World!")

file.close()
```

Important:

- If the file does not exist, it is created.
- If the file already contains data, `'w'` overwrites it.

---

# `writelines()`

`writelines()` writes multiple lines to a file.

```python
lines = [
    "Hello\n",
    "Welcome to Python\n",
    "File Handling\n"
]

file = open("example.txt", "w")

file.writelines(lines)

file.close()
```

---

# Appending to a File

Append mode `'a'` adds new content without deleting existing content.

```python
file = open("example.txt", "a")

file.write("\nThis is an additional line.")

file.close()
```

---

# Using `with open()` — Best Practice

Using `with open()` automatically closes the file after execution.

```python
with open("example.txt", "r") as file:
    content = file.read()

print(content)
```

There is no need to manually call:

```python
file.close()
```

---

# Checking Whether a File Exists

The `os` module can be used to check whether a file exists.

```python
import os

if os.path.exists("example.txt"):
    print("File exists!")
else:
    print("File not found!")
```

---

# Deleting a File

Use `os.remove()` to delete a file.

```python
import os

if os.path.exists("example.txt"):
    os.remove("example.txt")
    print("File deleted.")
else:
    print("File does not exist.")
```

---

# Working with Binary Files

Files such as:

- `.jpg`
- `.png`
- `.pdf`

should be opened in binary mode.

## Reading a Binary File

```python
with open("image.jpg", "rb") as file:
    data = file.read()

print(data)
```

---

# Writing a Binary File

```python
with open("new_image.jpg", "wb") as file:
    file.write(data)
```

---

# Common File Operations

| Operation | Method / Example |
|---|---|
| Open file | `open("example.txt", "r")` |
| Read entire file | `file.read()` |
| Read one line | `file.readline()` |
| Read all lines | `file.readlines()` |
| Write content | `file.write("Hello")` |
| Write multiple lines | `file.writelines(lines)` |
| Append content | Open using `'a'` |
| Check existence | `os.path.exists("file.txt")` |
| Delete file | `os.remove("file.txt")` |

---

# Quick Revision

```python
# Read
with open("example.txt", "r") as file:
    content = file.read()

    file.write("Hello")

with open("example.txt", "a") as file:
    file.write("\nMore text")
```

## Important Points

- `open()` opens a file.
- `'r'` reads.
- `'w'` writes and overwrites existing content.
- `'a'` appends.
- `'x'` creates a new file.
- `'b'` is used for binary files.
- `read()` reads the entire file.
- `readline()` reads one line.
- `readlines()` returns all lines as a list.
- `with open()` automatically closes the file.
- `os.path.exists()` checks whether a file exists.
- `os.remove()` deletes a file.
