# List and List Methods

A **list** in Python is an **ordered and mutable collection of elements**.

- **Ordered** means elements maintain their position.
- **Mutable** means elements can be added, removed, or changed.
- A list can contain values of different data types.

---

# Creating a List

## Empty List

```python
my_list = []
```

## List with Elements

```python
numbers = [1, 2, 3, 4, 5]
```

## List with Mixed Data Types

```python
mixed_list = [1, "Hello", 3.14, True]
```

---

# Common List Methods

| Method | Description |
|---|---|
| `append(x)` | Adds one element to the end of the list |
| `extend(iterable)` | Adds multiple elements from another iterable |
| `insert(index, x)` | Inserts an element at a specified index |
| `remove(x)` | Removes the first occurrence of a value |
| `pop(index)` | Removes and returns an element |
| `index(x)` | Returns the index of the first occurrence |
| `count(x)` | Counts how many times a value appears |
| `sort()` | Sorts the list in ascending order |
| `reverse()` | Reverses the order of the list |
| `copy()` | Returns a shallow copy of the list |
| `clear()` | Removes all elements from the list |

---

# `append()`

Adds one element to the end of a list.

```python
my_list.append(10)
```

Example:

```python
fruits = ["apple", "banana", "cherry"]

fruits.append("orange")

print(fruits)
```

Output:

```text
['apple', 'banana', 'cherry', 'orange']
```

---

# `extend()`

Adds all elements from another iterable to the list.

```python
my_list.extend([6, 7, 8])
```

Unlike `append()`, which adds one item, `extend()` adds multiple elements.

---

# `insert()`

Inserts an element at a specific index.

```python
my_list.insert(2, "Python")
```

Here, `"Python"` is inserted at index `2`.

---

# `remove()`

Removes the **first occurrence** of a specified value.

```python
my_list.remove(3)
```

---

# `pop()`

Removes and returns an element from the list.

```python
my_list.pop(2)
```

This removes the element at index `2`.

If no index is provided, `pop()` removes the last element.

```python
my_list.pop()
```

---

# `index()`

Returns the index of the first occurrence of a value.

```python
my_list.index(4)
```

---

# `count()`

Returns the number of times a value appears in the list.

```python
my_list.count(2)
```

---

# `sort()`

Sorts the list in ascending order.

```python
my_list.sort()
```

Example:

```python
fruits = ["apple", "banana", "cherry", "orange"]

fruits.sort()

print(fruits)
```

Output:

```text
['apple', 'banana', 'cherry', 'orange']
```

---

# `reverse()`

Reverses the order of elements in the list.

```python
my_list.reverse()
```

---

# `copy()`

Creates a shallow copy of the list.

```python
new_list = my_list.copy()
```

---

# `clear()`

Removes all elements from the list.

```python
my_list.clear()
```

After this, the list becomes empty.

---

# Quick Revision

```python
my_list.append(x)        # Add one element
my_list.extend(items)    # Add multiple elements
my_list.insert(i, x)     # Insert at index
my_list.remove(x)        # Remove first occurrence
my_list.pop(i)           # Remove and return element
my_list.index(x)         # Find index
my_list.count(x)         # Count occurrences
my_list.sort()           # Sort list
my_list.reverse()        # Reverse list
my_list.copy()           # Copy list
my_list.clear()          # Remove all elements
```

## Important Points

- Lists are ordered.
- Lists are mutable.
- Lists can contain different data types.
- `append()` adds one element.
- `extend()` adds multiple elements.
- `remove()` removes a value.
- `pop()` removes and returns an element.
