# Object-Oriented Programming in Python

**Object-Oriented Programming (OOP)** is a programming paradigm that organizes code into **objects** containing:

- Data → Attributes
- Behavior → Methods

---

# Key OOP Concepts

| Concept | Description |
|---|---|
| Class | Blueprint for creating objects |
| Object | Instance of a class |
| Attribute | Variable that stores data for an object |
| Method | Function inside a class |
| Encapsulation | Restricting direct access to data |
| Inheritance | Creating a class from another class |
| Polymorphism | Same method name with different behavior |
| Abstraction | Hiding implementation details |

---

# 1. Class and Object

A **class** is a blueprint used to create objects.

An **object** is an instance of a class containing specific data and behavior.

## Creating a Class

```python
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def display_info(self):
        return f"{self.brand} {self.model}"
```

Here:

- `Car` is the class.
- `brand` and `model` are attributes.
- `display_info()` is a method.

---

# Creating an Object

```python
car1 = Car("Toyota", "Camry")

print(car1.display_info())
```

Output:

```text
Toyota Camry
```

`car1` is an object or instance of the `Car` class.

# 2. Encapsulation

**Encapsulation** restricts direct access to an object's data and allows controlled access.

It helps protect data from direct modification.

### Example

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
```

Using the class:

```python
account = BankAccount(1000)

account.deposit(500)

print(account.get_balance())
```

Output:

```text
1500
```

Here:

```python
self.__balance
```

is treated as a private attribute.

### Why Use Encapsulation?

It protects data by restricting direct modification.

---

# 3. Inheritance

**Inheritance** allows a child class to inherit attributes and methods from a parent class.

### Example

```python
class Animal:
    def speak(self):
        return "Animal makes a sound"


class Dog(Animal):
    def speak(self):
        return "Bark"
```

Creating an object:

```python
dog = Dog()

print(dog.speak())
```

Output:

```text
Bark
```

Here:

```python
class Dog(Animal):
```

means `Dog` inherits from `Animal`.

### Why Use Inheritance?

- Promotes code reusability.
- Helps maintain cleaner code structure.

---

# 4. Multiple Inheritance

A class can inherit from multiple parent classes.

```python
class A:
    def method_a(self):
        return "Method A"


class B:
    def method_b(self):
        return "Method B"


class C(A, B):
    pass
```

Using the class:

```python
obj = C()

print(obj.method_a())
print(obj.method_b())
```

Output:

```text
Method A
Method B
```

`C` inherits features from both `A` and `B`.

---

# 5. Polymorphism

**Polymorphism** allows different classes to use the same method name with different behavior.

### Example

```python
class Bird:
    def fly(self):
        return "Birds can fly"


class Penguin(Bird):
    def fly(self):
        return "Penguins cannot fly"
```

```python
bird = Bird()
penguin = Penguin()

print(bird.fly())
print(penguin.fly())
```

Output:

```text
Birds can fly
Penguins cannot fly
```

Both classes use:

```python
fly()
```

but produce different behavior.

### Why Use Polymorphism?

It provides flexibility by allowing different classes to define the same method differently.

# 6. Abstraction

**Abstraction** hides implementation details.

The refresher demonstrates abstraction using the `ABC` module and `@abstractmethod`.

```python
from abc import ABC, abstractmethod


class Shape(ABC):

    @abstractmethod
    def area(self):
        pass
```

The child class provides the implementation.

```python
class Square(Shape):

    def __init__(self, side):
        self.side = side

    def area(self):
        return self.side * self.side
```

Using the class:

```python
square = Square(4)

print(square.area())
```

Output:

```text
16
```

### Why Use Abstraction?

It enforces consistent implementation across child classes.

# 7. Magic Methods

**Magic methods**, also called **dunder methods**, allow objects to behave like built-in Python types.

Examples:

- `__str__()`
- `__len__()`

### Example

```python
class Book:

    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __str__(self):
        return f"Book: {self.title}"

    def __len__(self):
        return self.pages
```

```python
book = Book("Python Basics", 300)

print(str(book))
print(len(book))
```

Output:

```text
Book: Python Basics
300
```

Here:

- `__str__()` defines the string representation.
- `__len__()` defines the behavior of `len()`.

# 8. Instance, Class and Static Methods

| Method Type | Description | Uses `self` | Uses `cls` |
|---|---|---|---|
| Instance Method | Works with instance attributes | Yes | No |
| Class Method | Works with class attributes | No | Yes |
| Static Method | Does not use class or instance variables | No | No |

---

# Instance Method

```python
def instance_method(self):
    return "Instance Method"
```

Uses `self` to work with an object.

---

# Class Method

Class methods use the `@classmethod` decorator and receive `cls`.

```python
@classmethod
def class_method(cls):
    return cls.class_var
```

---

# Static Method

Static methods use the `@staticmethod` decorator.

```python
@staticmethod
def static_method():
    return "Static Method"
```

---

# Complete Example

```python
class Example:

    class_var = "I am a class variable"

    def instance_method(self):
        return "Instance Method"

    @classmethod
    def class_method(cls):
        return cls.class_var

    @staticmethod
    def static_method():
        return "Static Method"
```

```python
obj = Example()

print(obj.instance_method())
print(Example.class_method())
print(Example.static_method())
```

Output:

```text
Instance Method
I am a class variable
Static Method
```
