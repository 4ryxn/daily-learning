# Lambda Functions

A **lambda function** is an anonymous, single-expression function defined using the `lambda` keyword.

It is commonly used for short and temporary operations where defining a complete function using `def` is unnecessary.

---

# Basic Syntax

```python
lambda arguments: expression
```

Where:

- `lambda` → keyword used to create the function
- `arguments` → input parameters
- `expression` → operation performed by the function

A lambda function contains a **single expression**, not multiple statements.

---

# Simple Lambda Function

```python
square = lambda x: x ** 2

print(square(5))
```

Output:

```text
25
```

Here:

```python
lambda x: x ** 2
```

takes `x` and returns its square.

---

# Lambda with `map()`

`map()` applies a function to each element of an iterable.

```python
numbers = [1, 2, 3, 4]

squared = list(
    map(lambda x: x**2, numbers)
)

print(squared)
```

Output:

```text
[1, 4, 9, 16]
```

The lambda:

```python
lambda x: x**2
```

is applied to every value.

---

# Lambda with `filter()`

`filter()` selects elements based on a condition.

```python
numbers = [1, 2, 3, 4, 5, 6]

evens = list(
    filter(lambda x: x % 2 == 0, numbers)
)

print(evens)
```

Output:

```text
[2, 4, 6]
```

Only numbers satisfying:

```python
x % 2 == 0
```

are kept.

---

# Lambda with `reduce()`

`reduce()` reduces an iterable to a single value.

It is imported from `functools`.

```python
from functools import reduce
```

### Example

```python
numbers = [1, 2, 3, 4]

product = reduce(
    lambda x, y: x * y,
    numbers
)

print(product)
```

Output:

```text
24
```

---

# Lambda with Multiple Arguments

Lambda functions can accept multiple parameters.

### Adding Two Numbers

```python
add = lambda x, y: x + y

print(add(3, 7))
```

Output:

```text
10
```

---

# Finding the Maximum of Two Numbers

```python
maximum = lambda x, y: x if x > y else y

print(maximum(10, 5))
```

Output:

```text
10
```

---

# Lambda in Sorting

Lambda functions can be used as sorting keys.

Consider:

```python
students = [
    ("Alice", 85),
    ("Bob", 78),
    ("Charlie", 92)
]
```

Sort according to the score:

```python
students.sort(
    key=lambda student: student[1]
)

print(students)
```

Output:

```text
[('Bob', 78), ('Alice', 85), ('Charlie', 92)]
```

The expression:

```python
student[1]
```

selects the second value of each tuple as the sorting key.

---

# When to Use Lambda Functions

Use lambda functions when:

- The function is short and simple.
- The function is only needed temporarily.
- It is being passed to another function such as `map()` or `filter()`.
- Defining a complete function with `def` would be unnecessary.

---

# When to Avoid Lambda Functions

Avoid lambda functions when:

- The logic is complex.
- Multiple operations or statements are required.
- A normal function using `def` would be easier to read.

---

# Lambda vs Normal Function

Normal function:

```python
def square(x):
    return x**2
```

Lambda equivalent:

```python
square = lambda x: x**2
```

For simple operations, lambda can be shorter.

For complex logic, use `def`.

## Important Points

- Lambda functions are anonymous functions.
- They use the `lambda` keyword.
- They contain one expression.
- They are useful for short, temporary functions.
- `map()` applies a function to each item.
- `filter()` selects items based on a condition.
- `reduce()` combines values into a single result.
- Use `def` instead when the logic becomes complex.
