# Match Case Statements

The `match-case` statement provides **pattern matching** in Python.

It was introduced in **Python 3.10** and works similarly to `switch` statements found in some other programming languages.

It is useful when one value needs to be compared against several possible patterns.

---

# Basic Syntax

```python
match value:
    case pattern1:
        # code
    case pattern2:
        # code
    case _:
        # default code
```

The `_` underscore acts as the **default case**.

It runs when none of the previous patterns match.

---

# Example: HTTP Status Codes

```python
def http_status(code):
    match code:
        case 200:
            return "OK"

        case 400:
            return "Bad Request"

        case 404:
            return "Not Found"

        case 500:
            return "Internal Server Error"

        case _:
            return "Unknown Status"
```

Calling the function:

```python
print(http_status(200))
```

Output:

```text
OK
```

Another example:

```python
print(http_status(404))
```

Output:

```text
Not Found
```

If a value does not match any defined case:

```python
print(http_status(300))
```

the default case runs:

```python
case _:
    return "Unknown Status"
```

---

# Matching Data Structures

`match-case` can also work with structured patterns such as tuples.

Consider:

```python
point = (3, 4)
```

We can match its structure:

```python
match point:
    case (0, 0):
        print("Origin")

    case (x, 0):
        print(f"X-Axis at {x}")

    case (0, y):
        print(f"Y-Axis at {y}")

    case (x, y):
        print(f"Point at ({x}, {y})")
```

Output:

```text
Point at (3, 4)
```

---

# Understanding the Tuple Patterns

## Origin

```python
case (0, 0):
```

Matches:

```python
(0, 0)
```

---

## Point on X-Axis

```python
case (x, 0):
```

Matches a point where the `y` value is `0`.

For example:

```python
(5, 0)
```

---

## Point on Y-Axis

```python
case (0, y):
```

Matches a point where the `x` value is `0`.

For example:

```python
(0, 7)
```

---

## Any Other Point

```python
case (x, y):
```

Matches a general two-value point.

---

# Important Features

- `match-case` was introduced in Python 3.10.
- It provides pattern matching.
- Multiple `case` blocks can be defined.
- `_` acts as the default case.
- Patterns can contain literal values.
- Patterns can bind values to variables.
- Patterns can also match structures such as tuples.
