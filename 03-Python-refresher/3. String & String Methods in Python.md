# String & String Methods

## What is a String?

A **string** is a sequence of characters enclosed inside single `' '` or double `" "` quotes.

### Example

```python
name = "Alice"
greeting = 'Hello'
```

Both `name` and `greeting` contain strings.

---

# Multiline Strings

Triple quotes are used to create strings that span multiple lines.

We can use:

```python
'''Text'''
```

or:

```python
"""Text"""
```

### Example

```python
message = """This is
a multiline
string."""
```

---

# String Indexing

Each character in a string has an index.

Python indexing starts from `0`.

Consider:

```python
text = "Python"
```

| Character | `P` | `y` | `t` | `h` | `o` | `n` |
|---|---:|---:|---:|---:|---:|---:|
| Positive Index | `0` | `1` | `2` | `3` | `4` | `5` |
| Negative Index | `-6` | `-5` | `-4` | `-3` | `-2` | `-1` |

### Accessing Characters

```python
text[0]
```

Output:

```text
'P'
```

Using a negative index:

```python
text[-1]
```

Output:

```text
'n'
```

`-1` refers to the last character of the string.

---

# String Slicing

**Slicing** is used to extract a portion of a string.

## Syntax

```python
string[start:stop]
```

The `start` index is included, while the `stop` index is excluded.

### Example

```python
text = "Python"

text[0:2]   # 'Py'
text[:3]    # 'Pyt'
text[3:]    # 'hon'
```

### Explanation

```python
text[0:2]
```

starts from index `0` and stops before index `2`.

Therefore:

```text
'Py'
```

If the starting index is omitted:

```python
text[:3]
```

Python starts from the beginning.

If the ending index is omitted:

```python
text[3:]
```

Python continues until the end of the string.

---

# String Immutability

Strings are **immutable**.

This means that once a string has been created, its individual characters cannot be directly modified.

### Example

```python
text = "Python"

text[0] = "J"
```

This produces an error.

A new string must be created instead of modifying an existing character directly.

# Common String Methods

Python provides several built-in methods for working with strings.

| Method | Description |
|---|---|
| `lower()` | Converts the string to lowercase |
| `upper()` | Converts the string to uppercase |
| `strip()` | Removes leading and trailing spaces |
| `replace(old, new)` | Replaces a substring |
| `split(sep)` | Splits a string into a list |
| `join(iterable)` | Joins multiple strings |
| `find(sub)` | Returns the index of the first occurrence |
| `count(sub)` | Counts occurrences of a substring |
| `startswith(prefix)` | Checks whether the string starts with a value |
| `endswith(suffix)` | Checks whether the string ends with a value |
| `isdigit()` | Checks whether all characters are digits |
| `isalpha()` | Checks whether all characters are letters |
| `isalnum()` | Checks whether all characters are letters or digits |

---

## `upper()`

Converts a string to uppercase.

```python
"hello".upper()
```

Output:

```text
'HELLO'
```

---

## `lower()`

Converts a string to lowercase.

```python
"HELLO".lower()
```

Output:

```text
'hello'
```

---

## `strip()`

Removes spaces from the beginning and end of a string.

```python
" Hello ".strip()
```

Output:

```text
'Hello'
```

---

## `replace()`

Replaces one substring with another.

```python
text = "I like Python"

text.replace("Python", "Data Science")
```

Output:

```text
'I like Data Science'
```

---

## `split()`

Splits a string into a list.

```python
"hello world".split()
```

Output:

```text
['hello', 'world']
```

A separator can also be specified.

```python
"a,b,c".split(",")
```

Output:

```text
['a', 'b', 'c']
```

---

## `join()`

Joins multiple strings together using a separator.

```python
"-".join(["2025", "04", "14"])
```

Output:

```text
'2025-04-14'
```

Here, `"-"` is inserted between every element.

---

## `find()`

Returns the index of the first occurrence of a substring.

```python
"python".find("th")
```

Output:

```text
2
```

The substring `"th"` starts at index `2`.

---

## `count()`

Counts how many times a substring occurs.

```python
"banana".count("a")
```

Output:

```text
3
```

---

## `startswith()`

Checks whether a string starts with a particular value.

```python
"Python".startswith("Py")
```

Output:

```text
True
```

---

## `endswith()`

Checks whether a string ends with a particular value.

```python
"Python".endswith("on")
```

Output:

```text
True
```

---

## `isdigit()`

Checks whether all characters are digits.

```python
"12345".isdigit()
```

Output:

```text
True
```

---

## `isalpha()`

Checks whether all characters are letters.

```python
"Python".isalpha()
```

Output:

```text
True
```

---

## `isalnum()`

Checks whether all characters are letters or digits.

```python
"Python123".isalnum()
```

Output:

```text
True
```

---

# String Formatting with f-Strings

**f-strings** are used to insert variables directly inside strings.

## Syntax

```python
f"Text {variable}"
```

### Example

```python
name = "Alice"
age = 30

message = f"Hello, {name}. You are {age} years old."

print(message)
```

Output:

```text
Hello, Alice. You are 30 years old.
```

F-strings make formatted strings cleaner and easier to read.
