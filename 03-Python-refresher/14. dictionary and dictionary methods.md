# Dictionary and Dictionary Methods

A **dictionary** in Python is a mutable collection used to store data in **key-value pairs**.

Each value is associated with a unique key, which allows efficient data retrieval and modification.

> The refresher describes dictionaries as unordered while also noting that modern Python maintains insertion order, with dictionaries being ordered as of Python 3.7.

---

# Creating a Dictionary

## Empty Dictionary

```python
empty_dict = {}
```

## Dictionary with Key-Value Pairs

```python
student = {
    "name": "Alice",
    "age": 25,
    "grade": "A"
}
```

Here:

- `"name"`, `"age"`, and `"grade"` are keys.
- `"Alice"`, `25`, and `"A"` are their corresponding values.

---

# Using the `dict()` Constructor

A dictionary can also be created using `dict()`.

```python
person = dict(
    name="John",
    age=30,
    city="New York"
)
```

---

# Accessing Dictionary Elements

Values can be accessed using their keys.

```python
student = {
    "name": "Alice",
    "age": 25,
    "grade": "A"
}

print(student["name"])
```

Output:

```text
Alice
```

---

# Using `get()`

The `get()` method can also access a value.

```python
print(student.get("age"))
```

Output:

```text
25
```

A useful advantage of `get()` is that a default value can be returned when the key does not exist.

```python
print(student.get("height", "Not Found"))
```

Output:

```text
Not Found
```

---

# Common Dictionary Methods

| Method | Description |
|---|---|
| `keys()` | Returns all keys |
| `values()` | Returns all values |
| `items()` | Returns key-value pairs as tuples |
| `get(key, default)` | Returns the value of a key or a default value |
| `update(dict2)` | Merges another dictionary into the dictionary |
| `pop(key, default)` | Removes a key and returns its value |
| `popitem()` | Removes and returns the last inserted key-value pair |
| `setdefault(key, default)` | Returns a key's value or inserts the default value |
| `clear()` | Removes all items |
| `copy()` | Returns a shallow copy |

---

# `keys()`

Returns all keys in the dictionary.

```python
student.keys()
```

---

# `values()`

Returns all values.

```python
student.values()
```

---

# `items()`

Returns key-value pairs as tuples.

```python
student.items()
```

This is useful when iterating over both keys and values.

```python
for key, value in student.items():
    print(key, ":", value)
```

---

# `update()`

Updates the dictionary using another dictionary.

```python
student.update({"age": 26})
```

The value of `"age"` becomes `26`.

---

# `pop()`

Removes a specified key and returns its value.

```python
student.pop("grade")
```

---

# `popitem()`

Removes and returns the **last inserted key-value pair**.

```python
student.popitem()
```

---

# `setdefault()`

Returns the value of a key if it exists.

If the key does not exist, it adds the key with the specified default value.

```python
student.setdefault("city", "Unknown")
```

---

# `copy()`

Creates a shallow copy of the dictionary.

```python
new_dict = student.copy()
```

---

# `clear()`

Removes all key-value pairs.

```python
student.clear()
```

---

# Adding and Updating Values

## Adding a New Key-Value Pair

```python
student = {
    "name": "Alice",
    "age": 25,
    "grade": "A"
}

student["city"] = "New York"
```

## Updating an Existing Value

```python
student["age"] = 26
```

---

# Iterating Over a Dictionary

```python
student = {
    "name": "Alice",
    "age": 26,
    "city": "New York"
}

for key, value in student.items():
    print(key, ":", value)
```

Output:

```text
name : Alice
age : 26
city : New York
```

---

# Dictionary Comprehension

A dictionary can also be created using comprehension.

```python
squares = {x: x**2 for x in range(1, 6)}

print(squares)
```

Output:

```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

---

# Key Properties of Dictionaries

- Dictionaries store data as key-value pairs.
- Dictionaries are mutable.
- Keys must be **unique**.
- Keys must be immutable types such as strings, numbers, or tuples.
- Values can be of any type and may be mutable.
- Modern Python dictionaries maintain insertion order.
