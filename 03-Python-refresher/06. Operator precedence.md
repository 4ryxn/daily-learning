# Operator Precedence

**Operator precedence** determines the order in which Python evaluates operators in an expression.

For basic arithmetic expressions, Python follows the **PEMDAS** rule:

1. Parentheses `()`
2. Exponents `**`
3. Multiplication `*`, Division `/`, Floor Division `//`, Modulus `%`
4. Addition `+`, Subtraction `-`

---

# 1. Parentheses `()`

Operations inside parentheses are evaluated first.

```python
result = (10 + 2) * 3

print(result)
```

Output:

```text
36
```

Explanation:

```text
(10 + 2) * 3
12 * 3
36
```

Without parentheses:

```python
result = 10 + 2 * 3
```

Python performs multiplication first.

```text
10 + (2 * 3)
10 + 6
16
```

---

# 2. Exponentiation `**`

Exponentiation has higher precedence than multiplication, division, addition, and subtraction.

```python
2 ** 3
```

Output:

```text
8
```

## Exponentiation is Evaluated Right to Left

```python
result = 2 ** 3 ** 2

print(result)
```

Python evaluates it as:

```python
2 ** (3 ** 2)
```

First:

```text
3 ** 2 = 9
```

Then:

```text
2 ** 9 = 512
```

Output:

```text
512
```

---

# 3. Multiplication, Division, Floor Division and Modulus

The following operators have the same precedence level:

```text
*
/
//
%
```

They are generally evaluated from **left to right**.

Example:

```python
result = 10 + 2 * 3
```

Multiplication happens before addition:

```text
10 + (2 * 3)
10 + 6
16
```

---

# 4. Addition and Subtraction

Addition and subtraction are evaluated after multiplication and division.

```python
result = 10 + 5 - 3
```

They are evaluated from left to right.

```text
10 + 5 = 15
15 - 3 = 12
```

---

# Operator Precedence Summary

| Priority | Operator | Description |
|---|---|---|
| 1 | `()` | Parentheses |
| 2 | `**` | Exponentiation |
| 3 | `*`, `/`, `//`, `%` | Multiplication and division operations |
| 4 | `+`, `-` | Addition and subtraction |

---

# Quick Revision

```python
10 + 2 * 3
# 16
```

```python
(10 + 2) * 3
# 36
```

```python
2 ** 3 ** 2
# 512
```

- Parentheses have the highest precedence.
- Exponentiation comes next.
- Multiplication and division operations come before addition and subtraction.
- Exponentiation is evaluated from right to left.
- Parentheses can be used to make the intended order of operations clear.
