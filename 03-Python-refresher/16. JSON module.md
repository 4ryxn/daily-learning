# JSON Module in Python

**JSON (JavaScript Object Notation)** is a lightweight data format used for exchanging data between applications.

It is commonly used in:

- APIs
- Web applications
- Configuration files
- Data exchange between servers and applications

Python provides the built-in `json` module for working with JSON.

---

# Importing the JSON Module

```python
import json
```

---

# Serialization

**Serialization**, also called **encoding** or **dumping**, means converting a Python object into JSON-formatted data.

Python provides:

- `json.dumps()`
- `json.dump()`

---

# `json.dumps()`

`json.dumps()` converts a Python object into a JSON string.

```python
import json

data = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}

json_string = json.dumps(data)

print(json_string)
print(type(json_string))
```

Output:

```text
{"name": "Alice", "age": 25, "city": "New York"}
<class 'str'>
```

The Python dictionary has been converted into a JSON-formatted string.

---

# `json.dump()`

`json.dump()` writes JSON data directly to a file.

```python
import json

data = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}

with open("data.json", "w") as file:
    json.dump(data, file)
```

---

# Deserialization

**Deserialization**, also called **decoding** or **loading**, means converting JSON-formatted data into Python objects.

Python provides:

- `json.loads()`
- `json.load()`

---

# `json.loads()`

`json.loads()` converts a JSON string into a Python object.

```python
import json

json_data = '{"name": "Alice", "age": 25, "city": "New York"}'

python_obj = json.loads(json_data)

print(python_obj)
print(type(python_obj))
```

Output:

```text
{'name': 'Alice', 'age': 25, 'city': 'New York'}
<class 'dict'>
```

---

# `json.load()`

`json.load()` reads JSON data from a file and converts it into a Python object.

```python
import json

with open("data.json", "r") as file:
    python_data = json.load(file)

print(python_data)
```

Output:

```text
{'name': 'Alice', 'age': 25, 'city': 'New York'}
```

---

# Formatting JSON Output

JSON output can be made easier to read using indentation.

```python
formatted_json = json.dumps(data, indent=4)

print(formatted_json)
```

Output:

```json
{
    "name": "Alice",
    "age": 25,
    "city": "New York"
}
```

---

# Common JSON Methods

| Method | Description |
|---|---|
| `json.dumps(obj)` | Converts a Python object to a JSON string |
| `json.dump(obj, file)` | Writes JSON data to a file |
| `json.loads(json_string)` | Converts a JSON string to a Python object |
| `json.load(file)` | Reads JSON data from a file |

---

# `dump` vs `dumps`

| Method | Purpose |
|---|---|
| `json.dump()` | Writes JSON to a file |
| `json.dumps()` | Returns JSON as a string |

---

# `load` vs `loads`

| Method | Purpose |
|---|---|
| `json.load()` | Reads JSON from a file |
| `json.loads()` | Reads JSON from a string |

---

# Quick Revision

```python
import json

json.dumps(data)       # Python object -> JSON string
json.dump(data, file)  # Python object -> JSON file

json.loads(data)       # JSON string -> Python object
json.load(file)        # JSON file -> Python object
```

## Important Points

- JSON is commonly used for data exchange.
- Python provides the `json` module.
- Serialization converts Python objects to JSON.
- Deserialization converts JSON back to Python objects.
- `dumps()` works with strings.
- `dump()` writes to files.
- `loads()` reads from strings.
- `load()` reads from files.
- `indent` improves JSON readability.
