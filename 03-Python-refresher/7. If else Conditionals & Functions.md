# If-Else Conditionals

Conditional statements allow a program to execute different blocks of code depending on whether a condition is `True` or `False`.

Python mainly uses:

- `if`
- `elif`
- `else`

Conditional statements are useful in Data Science for:

- Data filtering
- Data cleaning
- Categorizing data
- Decision-making
- Logic-based processing

---

# Basic `if` Statement

The `if` statement executes a block of code only when its condition is `True`.

## Syntax

```python
if condition:
    # code to execute
```

### Example

```python
x = 10

if x > 5:
    print("x is greater than 5")
```

Output:

```text
x is greater than 5
```

### How It Works

Python checks:

```python
x > 5
```

If the condition is `True`, the indented code under `if` executes.

If the condition is `False`, the block is skipped.

---

# `if-else` Statement

The `else` block runs when the `if` condition is `False`.

## Syntax

```python
if condition:
    # runs when condition is True
else:
    # runs when condition is False
```

### Example

```python
x = 3

if x > 5:
    print("x is greater than 5")
else:
    print("x is not greater than 5")
```

Output:

```text
x is not greater than 5
```

---

# `if-elif-else` Statement

Use `elif`, meaning **else if**, when multiple conditions need to be checked.

## Syntax

```python
if condition1:
    # code
elif condition2:
    # code
else:
    # code
```

### Example

```python
x = 5

if x > 10:
    print("x is greater than 10")
elif x > 5:
    print("x is greater than 5 but not more than 10")
elif x == 5:
    print("x is exactly 5")
else:
    print("x is less than 5")
```

Output:

```text
x is exactly 5
```

## How It Works

Conditions are checked from **top to bottom**.

The first condition that becomes `True` executes, and the remaining conditions are skipped.

---

# Example: Categorizing Data

```python
age = 25

if age < 18:
    category = "Minor"
elif age < 65:
    category = "Adult"
else:
    category = "Senior Citizen"

print("Category:", category)
```

Output:

```text
Category: Adult
```

This is useful when continuous values need to be converted into categories.

# Using Conditions with Pandas

Conditional logic can also be applied to DataFrame values.

```python
import pandas as pd

data = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Score": [85, 40, 75]
}

df = pd.DataFrame(data)

df["Result"] = df["Score"].apply(
    lambda x: "Pass" if x >= 50 else "Fail"
)

print(df)
```

The condition:

```python
"Pass" if x >= 50 else "Fail"
```

assigns:

- `"Pass"` when the score is at least `50`
- `"Fail"` otherwise

This demonstrates how conditional logic can be useful for Data Science tasks.

# Functions Used with Conditional Logic

The refresher also uses a function together with conditional logic and `match-case`.

A function can be defined using `def`.

### Example

```python
def http_status(code):
    if code == 200:
        return "OK"
    else:
        return "Unknown Status"
```

Here:

- `def` defines the function.
- `http_status` is the function name.
- `code` is the input given to the function.
- `return` sends a result back.

The function can be called using:

```python
print(http_status(200))
```

Output:

```text
OK
```

# Quick Revision

## `if`

Runs when a condition is `True`.

```python
if condition:
    ...
```

## `if-else`

Provides an alternative when the condition is `False`.

```python
if condition:
    ...
else:
    ...
```

## `if-elif-else`

Handles multiple conditions.

```python
if condition1:
    ...
elif condition2:
    ...
else:
    ...
```

### Important Points

- Conditions are evaluated as `True` or `False`.
- Indentation defines the code belonging to each condition.
- `elif` is used when multiple conditions must be checked.
- Conditions are checked from top to bottom.
- The first `True` branch executes.
- Conditional statements are useful for filtering, cleaning, categorization, and decision-making in Data Science.
