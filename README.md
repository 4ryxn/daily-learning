# Daily Learning

Documenting my data science learning journey through hands-on practice in Python, SQL, statistics, machine learning, deep learning, and AI.

## About

This repository is a growing collection of notes, exercises, experiments, and small projects created while building practical data science skills. The focus is on learning by doing: understanding the concepts, writing the code, and applying both to real-world-style problems.

## Learning Areas

- **Python** — fundamentals, data structures, scripting, and data analysis
- **SQL** — querying, joins, aggregations, and database problem-solving
- **Statistics** — probability, hypothesis testing, distributions, and inference
- **Machine Learning** — supervised and unsupervised learning, evaluation, and feature engineering
- **Deep Learning** — neural networks and modern deep learning workflows
- **AI** — core concepts, tools, and practical applications
